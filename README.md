# The Alternative Desktop Synthesizer Garden

A landing page for a collection of desktop-native synthesizer instruments. Built as a single HTML file with embedded CSS, JavaScript, and Web Audio API synthesis.

## Live Site

[thealternativedesktopsynthesizer.garden](https://thealternativedesktopsynthesizer.garden)

## Instruments

Each instrument lives on its own subdomain:

- [QWERTY Tempered](https://qwertytempered.thealternativedesktopsynthesizer.garden) — Equal-tempered instrument using your keyboard
- [Window Candy](https://windowcandy.thealternativedesktopsynthesizergarden.garden) — Nostalgia rendered as sound
- [Labyrinth](https://labyrinth.thealternativedesktopsynthesizer.garden) — Autonomous self-tending synth

## Features

- **Ambient hum** — A living Cmaj9#11 chord that blooms in over ~18 seconds with pitch glide, filter sweeps, chorus, and reverb
- **Plink sound** — A celestial chord hit with long echo and reverb on button clicks
- **"Don't Explore" chaos** — Screen shake, color flash, and a wall of dissonant noise
- **Procedural stars and fireflies** — Animated background elements
- **Scroll-triggered animations** — Elements fade in as they enter the viewport
- **Responsive design** — Works on desktop and mobile (though the synths themselves are desktop-only)

## Tech

- Vanilla HTML/CSS/JS — no frameworks, no build step
- Web Audio API for all sound synthesis
- CSS custom properties, gradients, and animations
- IntersectionObserver for scroll animations
